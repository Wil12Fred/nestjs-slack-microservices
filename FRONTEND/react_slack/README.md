# react_slack

The web client of [nestjs-slack-microservices](../../README.md): login,
sign-up, workspace and channel menus, and the chat view. The root README
describes the variables in `.env.example` and how to run it with the
backend.

```bash
npm ci
npm run lint
npm run build
npm test     # set CI=true (or pass -- --watchAll=false) to run once
npm start    # dev server on :3000, plus the Tailwind watcher
```
